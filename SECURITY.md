# Security policy

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/HH1st/hoho-avatar/security/advisories/new) for security-sensitive reports. Include affected versions, reproduction steps, impact, and any suggested mitigation.

Do not publish exploit details in a public issue before maintainers have had a reasonable opportunity to investigate and release a fix.

The project does not currently publish a formal support window. Security fixes target the latest released version and the `main` branch.
