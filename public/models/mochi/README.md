# Mochi

Original ceramic robot character modeled in Blender for Hoho Avatar. Released under the repository MIT license.

- Source: `assets/blender/mochi.blend`
- Generator: `scripts/blender/create_mochi.py` (Blender 4.5 LTS)
- Runtime: `mochi.glb`, glTF 2.0, Y up, front +Z
- Mouth shape keys: `mouth_small`, `mouth_large`, `mouth_wide`, `mouth_round`
- Eyes: `blink` on both eye meshes

No external meshes, images or texture assets were used.
